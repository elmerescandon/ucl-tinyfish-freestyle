# event-simplifier

Agent that simplifies any event. Give it messy event input
(a URL to an event page, a wall of text, a calendar blob) and it returns
the simplified version: what, when, where, cost, and what you actually
need to do next.

Powered by [TinyFish](https://tinyfish.ai) for web search / fetch /
browser automation.

## Status

Bootstrap. Scope and contract in progress.
